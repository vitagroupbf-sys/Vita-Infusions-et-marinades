## Modifier les produits, prix et numéros

Ouvrir `index.html` et modifier la section `var P=[ ... ]` (produits et prix) et la ligne `var WA="22678958395";` (numéro WhatsApp, sans le +). Le numéro d'appel se trouve dans la ligne `href="tel:+22674219393"`.
